# Boss Rush

## GitHub Pages
Upload `index.html` and the entire `assets/` folder to the repository's published root. Soundtracks are loaded from `assets/Music/`.

## Hitbox overlay
During a run, press **H** to toggle hitbox debug drawing. It outlines player collision circles, living boss bodies, projectiles, pickups, hazard circles, and active boss attack lanes. Press **H** again to hide the overlay.

The Boss 4 alliance fight gives each boss its own hit target and health bar. Defeating one stops that boss from attacking; defeat both to continue.
